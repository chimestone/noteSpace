# 第2题
R 占块数 20000 ÷ 40 = 500 块  
S 占块数 1200 ÷ 30 = 40 块
1. R 上没有索引，select * from R；因为没有索引，需要顺序扫描整个关系 R。磁盘块读写次数：500 次
2. R 中 A 为主码，A 有 3 层 B+ 树索引，select * from R where A=10；A 是主码，因此最多找到 1 个元组。3 层 B+ 树：根节点 → 中间节点 → 叶节点，访问索引需要 3 次 I/O，再读取目标数据块 1 次 I/O，总次数：3 + 1 = 4 次
3. 嵌套循环连接 R⋈S，嵌套循环连接代价：Br + Br × Bs = 500 + 500 × 40 = 20500 次
4. 排序合并连接 R⋈S  
（1）若 R 和 S 在 B 属性上已经有序，只需扫描一次：Br + Bs = 500 + 40 = 540 次  
（2）若 R 和 S 在 B 属性上无序，先排序，再进行归并连接。排序代价按外部排序估算：R 排序：2 × Br × 2 = 2 × 500 × 2 = 2000 次；S 排序：2 × Bs × 2 = 2 × 40 × 2 = 160 次；归并连接代价：Br + Bs = 500 + 40 = 540 次；总次数：2000 + 160 + 540 = 2700 次
# 第3题
1. 原始关系代数表达式
πCname  
(σStudent.Sno=SC.Sno ∧ SC.Cno=Course.Cno ∧ Student.Smajor='信息管理与信息系统'  
(Student × Course × SC))
原始语法树：
```
            πCname
                │
               σ条件
                │
        Student × Course × SC
```
其中条件为：
Student.Sno=SC.Sno  
SC.Cno=Course.Cno  
Student.Smajor='信息管理与信息系统'
2. 优化过程
先对 Student 做选择：σSmajor='信息管理与信息系统'(Student)
然后将Student.Sno=SC.Sno转换为：Student ⋈ SC
将SC.Cno=Course.Cno转换为：SC ⋈ Course
只保留需要属性。
优化后关系代数表达式：
πCname  
(  
(πSno(σSmajor='信息管理与信息系统'(Student)))  
⋈Student.Sno=SC.Sno  
(πSno,Cno(SC))  
⋈SC.Cno=Course.Cno  
(πCno,Cname(Course))  
)
3. 优化后标准语法树
```
                         πCname
                             │
                  ⋈(SC.Cno = Course.Cno)
                      /               \
      ⋈(Student.Sno = SC.Sno)      πCno,Cname
             /          \                │
         πSno         πSno,Cno        Course
           │               │
σSmajor='信息管理与信息系统'          SC
           │
        Student
```

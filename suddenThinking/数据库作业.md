# 第九题
1. 系统崩溃后，先从日志中找到最近一次检查点记录，以减少扫描日志范围。
2. 读取检查点时正在执行的事务，建立活动事务表。
3. 从检查点开始向后扫描日志，已提交事务加入REDO队列，未提交事务加入UNDO队列，已回滚事务不处理。
4. 按日志正向执行REDO，对已提交事务重新执行更新操作，保证结果写回数据库。
5. 按日志逆向执行UNDO，撤销未提交事务的所有修改，使数据库恢复一致性。

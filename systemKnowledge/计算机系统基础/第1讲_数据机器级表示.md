# 第一讲：数据的机器级表示

## 核心知识点

### 1. 码点与编码

- n 位存储单元有 2^n 种状态，每个状态称为一个"码点"
- 码点本身只是 0/1 序列，**没有语义**
- 指令决定如何解释码点（同一个 0xFF 可以被当作 -1 或 255）

### 2. 补码（有符号整数）

- **正数**：本身二进制，最高位 = 0
- **负数 X**：`|X| 的二进制取反 + 1`，最高位 = 1
- **数学本质**：`[X]补 = X (mod 2^n)`，在模 2^n 意义下取值
- **最高位权重为负**：最高位权重 = `-2^(n-1)`，其余位权重为正。这使符号成为数值的一部分，加减法无需单独处理符号
- **范围**：n 位 → `-2^(n-1) ~ 2^(n-1) - 1`，负数比正数多一个
- 特殊值 `1000 0000`（8位）= -128，绝对值无法用 8 位表示

### 3. 无符号数（原码）

- n 位范围：`0 ~ 2^n - 1`
- 与有符号数混用时有类型转换陷阱

### 4. 四个标志位（EFLAGS）

| 标志 | 全称          | 含义                                  |
| ---- | ------------- | ------------------------------------- |
| SF   | Sign Flag     | 结果最高位 → 有符号结果的正负        |
| ZF   | Zero Flag     | 结果是否为 0                          |
| OF   | Overflow Flag | **有符号数**运算是否超出范围    |
| CF   | Carry Flag    | **无符号数**运算是否有进位/借位 |

**溢出判断口诀**：

- OF：正+正=负、负+负=正 → 溢出（反之不溢出）
- CF：无符号结果超出 0~2^n-1 → 进位
- OF 和 CF 各自独立，管各自的领域

### 5. 补码运算规则

- `[A+B]补 = [A]补 + [B]补`
- `[A-B]补 = [A]补 + [-B]补`
- 加减法用同一套电路

### 6. C 语言类型转换陷阱

- 有符号与无符号混用时，**一律按无符号数运算**
- `unsigned short` 赋 -1 → 变成 65535（0xFFFF）
- `%d` 打印时，short 会被提升为 int（符号扩展 vs 零扩展）

## 薄弱点记录

- [ ] SF 判断不稳定：需牢记 SF 只看结果的**最高位**，0 为 SF=0，1 为 SF=1
- [ ] OF 溢出判断需强化：关键是 **"正+正=负、负+负=正→溢出"**，不是"结果有无进位"
- [ ] 已知补码求原值的方向不能搞反：正数直接算，负数"取反+1"得出绝对值再加负号

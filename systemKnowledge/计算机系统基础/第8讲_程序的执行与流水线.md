# 第八讲：程序的执行与流水线

## 一、指令执行的 6 个阶段

取指(IF) → 译码(ID) → 取操作数(OF) → 执行(EX) → 存结果(WB) → 计算下条地址

## 二、流水线原理

- 串行：一条执行完再取下一条 → 效率低
- 流水线：多条指令的不同阶段同时进行 → 理想情况下每周期完成一条
- 时钟周期 = 最慢阶段的耗时 + 寄存器开销

## 三、CISC vs RISC

| 特征 | CISC (x86) | RISC (ARM) |
|------|-----------|-----------|
| 指令数量 | 多/复杂 | 少/精 |
| 指令长度 | 可变 | 固定 |
| 访存方式 | 任意指令 | 仅 load/store |
| 流水线 | 需拆微操作 | 天然适配 |
| 控制器 | 微程序(慢) | 硬连线(快) |

Intel：CISC壳 + RISC核

## 四、有利于流水线的指令集特征

1. 指令长度一致 → 取指译码简化
2. 指令格式规整 → 寄存器位置固定
3. load/store 风格 → 减少访存阶段差异
4. 数据对齐 → 减少访存次数

| 编译选项                 | 作用                              |
| -------------------- | ------------------------------- |
| -fno-stack-protector | 关闭栈保护（canary），否则溢出会被检测到直接崩溃     |
| -no-pie              | 关闭地址随机化（PIE），让函数地址固定，方便我们填写     |
| -fcf-protection=none | 关闭控制流保护(CFG)                    |
| -z execstack         | 允许栈上的代码执行                       |
| -DU*                 | 宏定义，决定getbuf里面额外声明哪个局部变量，影响栈帧布局 |

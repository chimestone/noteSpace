# 第九讲：存储层次与 Cach

## 一、存储层次

```
寄存器 → L1 Cache → L2 Cache → 主存 → SSD → 磁盘
速度递减 ← ← ← ← ← ← ← ← ← ← ← 容量递增
```

## 二、局部性原理

| 类型 | 含义 | 例子 |
|------|------|------|
| 时间局部性 | 刚访问的可能再被访问 | 循环变量 i |
| 空间局部性 | 邻近的可能被访问 | 数组连续遍历 |

## 三、Cache 工作原理

- 命中：直接返回 → 快
- 未命中：从主存取一个块到 Cache → 慢
- 平均时间：`Ta = Tc + (1-p) × Tm`
- p 通常 > 95%，所以 Ta ≈ Tc

## 四、编写 Cache 友好的代码

- 按内存连续方向访问（二维数组按行遍历）
- 内层循环访问的数据尽量小且连续
- 避免跳跃式访问（按列遍历二维数组）

# 第十讲：I/O 与异常控制流

## 一、异常控制流

| 类型 | 来源 | 特征 |
|------|------|------|
| 中断 | 外部设备 | 异步 |
| 异常 | 指令执行 | 同步 |

## 二、处理流程

发生中断/异常 → 保存现场 → 查中断向量表 → 执行处理程序 → IRET 返回

## 三、整数除 0 vs 浮点数除 0

- 整数除 0 → CPU 硬件检测 → 触发异常 → 操作系统介入 → 程序被终止
- 浮点数除 0 → FPU 按 IEEE 754 返回 inf/NaN → 不触发异常 → 程序继续

## 四、存储器分类

| 维度 | 类型 |
|------|------|
| 存取方式 | RAM / SAM / DAM / CAM |
| 可更改性 | RAM / ROM |
| 断电保持 | 易失 / 非易失 |

# 第四讲：C 控制结构的机器级表示

## 核心思想

所有 C 控制流底层只有三种指令的组合：

```
cmp + jxx(条件跳转) + jmp(无条件跳转)
```

---

## 一、if-else 模板

```asm
        计算条件
        jxx  else_label    ; 取条件"不成立"的跳转
        then 语句
        jmp  end_label
else_label:
        else 语句
end_label:
```

**跳转指令选择口诀**：选否定你条件的那个跳转。

| 条件不成立时 | 用 |
|------------|-----|
| x <= y | `jle` |
| x < y | `jl` |
| x == y | `jne` |
| x != y | `je` |
| x >= y | `jl` |
| x > y | `jle` |

---

## 二、switch —— 跳转表

- case 值**密集且连续** → 生成跳转表，O(1) 定位
- case 值**稀疏或分散** → 退化为 if-else 逐个比较

```asm
jmp *(, %eax, 4)    ; 以 eax 为下标查跳转表
```

---

## 三、循环骨架

### do-while（至少执行一次）
```asm
loop_label:
        循环体
        条件判断
        jxx loop_label
```

### while / for（可能零次）
```asm
        初始化
        jmp  test
body:
        循环体
        迭代
test:
        条件判断
        jxx body
end:
```

**for = 初始化 + while（条件）+ 迭代**

---

## 四、循环 vs 递归

| 维度 | 循环 | 递归 |
|------|------|------|
| 栈帧 | 不新增 | 每次调用增一个 |
| call/ret | 无 | 每次有 |
| push/pop 参数 | 无 | 每次有 |
| 现场保护 | 无 | 每次 push/pop 寄存器 |
| 大 n 风险 | 无 | 栈溢出 |

**结论**：能用循环就不用递归。

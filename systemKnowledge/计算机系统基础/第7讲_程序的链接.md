# 第七讲：程序的链接

## 一、链接的两大任务

| 任务 | 内容 |
|------|------|
| 符号解析 | 将符号引用与唯一定义关联 |
| 重定位 | 合并 .o 后分配最终地址，修正指令中的引用 |

## 二、符号分类

| 类型 | 含义 |
|------|------|
| 全局符号 | 本模块定义，可被其他模块引用 |
| 外部符号 | 其他模块定义，本模块引用 |
| 局部符号 | 本模块定义且仅本模块使用（static）|

**不是符号**：普通局部变量、函数参数。

## 三、强符号 vs 弱符号

| 类型 | 定义 |
|------|------|
| 强符号 | 函数名、已初始化的全局变量 |
| 弱符号 | 未初始化的全局变量 |

**规则**：多个强符号→报错；一强多弱→选强；全弱→随便选

## 四、ELF 目标文件结构

| 节 | 内容 |
|----|------|
| `.text` | 代码 |
| `.data` | 已初始化全局变量 |
| `.bss` | 未初始化全局变量（不占磁盘）|
| `.rodata` | 只读数据 |
| `.symtab` | 符号表 |
| `.rel.text` / `.rel.data` | 重定位信息 |

## 五、重定位类型

| 类型 | 用途 |
|------|------|
| `R_386_PC32` | 函数调用，PC 相对地址 |
| `R_386_32` | 变量访问，绝对地址 |

## 六、静态库

```bash
ar rcs mylib.a *.o              # 打包
gcc -static -o prog main.o ./mylib.a  # 静态链接
```

## 七、加载

`execve` → 加载器映射到内存 → EIP 指向 `_start` → 调用 `main`

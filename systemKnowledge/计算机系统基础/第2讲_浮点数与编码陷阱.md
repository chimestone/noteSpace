# 第二讲：浮点数与编码陷阱

## 核心知识点

### 1. IEEE 754 单精度浮点数（float，32位）

```
[符号 1bit] [指数 8bit] [尾数 23bit]
```

- **符号位**：0 正，1 负
- **指数**：移码存储，实际存 = 真实指数 n + 127（偏置常数）
  - n = 0 → 存 127 (0111 1111)
  - n = -1 → 存 126 (0111 1110)
- **尾数**：规格化 `1.XXXX × 2^n`，前导 1 **隐含**不存，只存 `.XXXX` 部分
  - 有效精度 = 1 + 23 = **24 位**

### 2. 规格化过程

1. 小数转二进制
2. 写成 `±1.XXXX × 2^n` 的形式
3. 符号位填 0/1
4. 指数填 n+127
5. 尾数填 .XXXX，后面补 0

### 3. 浮点数的根本缺陷

- 很多十进制小数在二进制中是**无限循环小数**（如 0.1 = 0.00011[0011]...）
- 24 位精度截断导致**存储值与真值之间存在误差**
- float 误差 ≈ 10⁻⁸ 量级，double 误差 ≈ 10⁻¹⁶ 量级

### 4. 精度不均匀性

- 数值越大，相邻可表示数的**间隔越大**
- 在 2^24 ≈ 1670 万附近，float 间隔 = 2，只能表示偶数
- 这是宽度和精度之间的权衡

### 5. IEEE 754 特殊值

| 值 | 含义 | 产生方式 |
|----|------|---------|
| +∞ | 正无穷 | 正数 ÷ 0 |
| -∞ | 负无穷 | 负数 ÷ 0 |
| NaN | 不是数 | 0÷0, ∞-∞, ∞×0 |

- 整数除 0 → **程序崩溃**
- 浮点数除 0 → **返回 ∞**，不崩溃

### 6. float vs double

| 类型 | 位数 | 指数 | 尾数 | 有效精度 |
|------|------|------|------|---------|
| float | 32 | 8 | 23 | 24 位 |
| double | 64 | 11 | 52 | 53 位 |

### 7. 爱国者导弹教训

- 0.1 用 24 位定点小数存储，误差 ≈ 9.54×10⁻⁸
- 连续运行 100 小时，累积时间误差 = 100×3600×10 × 9.54×10⁻⁸ ≈ 0.343 秒
- 飞毛腿速度 2000m/s → 距离误差 ≈ 687 米 → 拦截失败
- 改用 32 位定点：误差仅 0.67 米

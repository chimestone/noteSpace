# 第五讲：过程调用与栈帧

## 一、堆栈基础

- 栈向**低地址**增长，ESP 指向栈顶（最低地址）
- `pushl %eax`：`esp -= 4; *(int*)esp = eax`（先移指针，再写数据）
- `popl %eax`：`eax = *(int*)esp; esp += 4`

## 二、栈帧标准布局

```
高地址
┌──────────────┐
│ 调用者旧 ebp   │
├──────────────┤
│ 参数 N         │ ← 最后压入的（最右边参数）
│ ...           │
│ 参数 1         │ ← 8(%ebp)  第一个参数
├──────────────┤
│ 返回地址       │ ← 4(%ebp)  call 指令压入
├──────────────┤
│ 旧 EBP        │ ← (%ebp)  被调函数保存的
├──────────────┤
│ 局部变量 1     │ ← -4(%ebp)
│ 局部变量 2     │ ← -8(%ebp)
├──────────────┤
│ ...           │ ← ESP
└──────────────┘
```

**铁律**：
- 参数 → `+n(%ebp)`
- 局部变量 → `-n(%ebp)`
- 返回值 → 放 `EAX` 中

## 三、函数调用的完整流程

```
主调方:
  ① push 参数（C 语言从右到左）
  ② call function（压入返回地址，跳到被调函数）

被调方:
  ③ push %ebp（保存主调方的 ebp）
  ④ mov %esp, %ebp（建立自己的栈帧基址）
  ⑤ sub $N, %esp（分配局部变量空间）
  ⑥ ... 执行函数体 ...
  ⑦ leave（= mov %ebp, %esp; pop %ebp）
  ⑧ ret（= pop eip）

主调方:
  ⑨ add $N, %esp（清理参数）
```

## 四、传值 vs 传址

| 方式 | 栈上传递什么 | 能否改原变量 |
|------|-------------|-------------|
| 传值 `swap(a,b)` | 变量的**值** | 不能 |
| 传址 `swap(&a,&b)` | 变量的**地址**（也是值）| 能（通过间接寻址）|

**C 语言只有传值**，传址的本质是传"地址值"。

## 五、递归的代价

每次递归调用都完整重复栈帧创建过程：
- push 参数 + call + push ebp + sub $N, %esp
- ... 函数体 ...
- leave + ret

n 次调用 = n 套完整的栈帧。n 大时栈溢出。

## 六、局部变量生命周期

局部变量分配在被调函数的栈帧中，函数返回后（leave）栈帧被回收。返回局部变量的地址 → 悬空指针。

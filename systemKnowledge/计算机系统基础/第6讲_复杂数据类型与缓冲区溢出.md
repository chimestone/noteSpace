# 第六讲：复杂数据类型与缓冲区溢出

## 一、数组的底层

- 数组 = 一段连续内存，访问方式 = 首地址 + 下标 × sizeof(元素)
- 汇编用**基址加变址寻址**：`(%ebx, %esi, 4)`
- 局部数组在栈上（`-n(%ebp)`），全局数组在数据段
- 数组名 = 首元素地址，`a` 等价于 `&a[0]`

### 指针与数组
- `p + i` → 地址 + i × sizeof(*p)
- `*p` 必须用寄存器间接寻址 `(%eax)`，不能直接写固定偏移
- 指针本身是变量，存的是地址值，有自己的内存位置

## 二、多维数组

- 按**行优先**存储，连续一维排列
- `a[i][j]` 偏移 = `i × 每行元素数 × sizeof(元素) + j × sizeof(元素)`

## 三、结构体

- 成员按定义顺序连续存放
- 访问成员 = 首址 + 成员偏移量
- 按值传结构体效率低（全复制），大结构体应用指针传

### 对齐规则
- 每个成员放在自身大小倍数的偏移处
- 结构体总大小为最大成员大小的倍数
- 示例：`{char, int, char}` = `1 + 3(填充) + 4 + 1 + 3(填充)` = 12 字节

## 四、联合体

- 所有成员共享同一块内存
- 大小 = 最大成员的大小
- 成员间相互覆盖

## 五、数据对齐

- CPU 一次最多读写 8 字节（64 位）
- 操作数跨边界 → 多次访存 → 效率降低
- 编译器默认为变量对齐，空间换时间

## 六、缓冲区溢出攻击

### 原理
局部数组在栈上，向上覆盖会改写返回地址。攻击者构造超长输入，把返回地址替换为恶意代码入口。

### 攻击字符串结构
```
[16字节填充] [4字节覆盖旧ebp] [4字节恶意代码地址]
```

### 防范
- 栈保护（Canary）：返回地址旁放随机值
- ASLR：随机化地址空间
- NX：栈不可执行

## 薄弱点记录

- [ ] 指针解引用 `*p` 必须通过 `(%eax)` 间接寻址，不能用固定偏移
- [ ] 结构体对齐填充字节数计算：尾部对齐到最大成员大小的倍数
- [ ] 缓冲区溢出的攻击字符串结构需记住

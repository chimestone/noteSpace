# 第三讲：汇编基础与寻址方式

## 一、基础符号系统（AT&T 格式）

| 符号                                     | 含义       | 示例                                          |
| ---------------------------------------- | ---------- | --------------------------------------------- |
| `%`                                    | 寄存器前缀 | `%eax`, `%ebx`                            |
| `$` | 立即数前缀 | `$100`, `$0x1A` |            |                                               |
| `b/w/l`                                | 长度后缀   | `movb`(8位), `movw`(16位), `movl`(32位) |

**AT&T vs Intel 格式**：源和目的顺序相反。

- AT&T: `movl $100, %eax`（源→目的）
- Intel: `mov eax, 100`（目的←源）

---

## 二、七大寻址方式

核心公式：**EA = 位移量 + 基址寄存器 + 变址寄存器 × 比例因子**

| #  | 寻址方式   | 格式             | EA             | 等价 C           |
| -- | ---------- | ---------------- | -------------- | ---------------- |
| ① | 立即       | `$n`           | n 本身         | `int x = 100;` |
| ② | 寄存器     | `%R`           | R 的值         | `x = a;`       |
| ③ | 直接       | `addr`         | addr           | `x = global;`  |
| ④ | 寄存器间接 | `(%R)`         | `[R]`        | `x = *p;`      |
| ⑤ | 变址       | `X(%R)`        | `R+X`        | `x = p[3];`    |
| ⑥ | 基址加变址 | `X(%BR,%IR,S)` | `X+BR+IR×S` | `arr[i]`       |

**比例因子 S**：1(char), 2(short), 4(int/float), 8(double/long long)

**两条铁律**：

- 源和目的不能同时为内存操作数
- 立即数不能做目的操作数

---

## 三、核心指令

### 1. 传送类

| 指令                 | 功能            | 注意                     |
| -------------------- | --------------- | ------------------------ |
| `mov[b/w/l]`       | 数据传送        | 不影响标志位             |
| `movs[b/w][b/w/l]` | 符号扩展传送    | 高位填符号位             |
| `movz[b/w][b/w/l]` | 零扩展传送      | 高位填 0                 |
| `lea`              | 取地址/地址计算 | **不访存**，仅计算 |

**LEA vs MOV 关键区别**：

```asm
leal 8(%ebp), %eax   ; eax = ebp+8（算地址）
movl 8(%ebp), %eax   ; eax = *(ebp+8)（取数据）
```

### 2. 算术运算类
| **指令**                                  | **功能说明**     | **C语言代码**                                               | **对应的汇编实例 (AT&T语法)**                                                                                          | **考点与避坑提示**                                                                 |
| --------------------------------------- | ------------ | ------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| **add / sub**                           | 加法 / 减法      | `a = a + b;`<br><br>  <br><br>`a = a - b;`              | `addl %ebx, %eax`<br><br>  <br><br>`subl %ebx, %eax`                                                          | **AT&T方向相反**：`subl S, D` 是 `D = D - S`。修改全部状态标志位。                           |
| **inc / dec**                           | 自增 / 自减      | `a++;`<br><br>  <br><br>`a--;`                          | `incl %eax`<br><br>  <br><br>`decl %eax`                                                                      | 操作数只有 1 个。注意：它们**不影响进位标志(CF)**，但会影响其他标志位。                                   |
| **neg**                                 | 求补（取反+1）     | `a = -a;`                                               | `negl %eax`                                                                                                   | 就是求相反数。如果 `%eax` 是 0，CF=0；只要 `%eax` 不是 0，CF=1。                              |
| **cmp**                                 | 比较（做减法，不存结果） | `if (a < b)`                                            | `cmpl %ebx, %eax`<br><br>  <br><br>`jl .L1`                                                                   | **地狱级易错点**：`cmpl B, A` 算的是 **`A - B`**！结果丢弃，专门为了给后面的 `jxx` 设标志位。            |
| **imul / mul**                          | 乘法 (有符号/无符号) | `int c = a * b;`<br><br>  <br><br>`unsigned c = a * b;` | **双操作数(常用)**:<br><br>  <br><br>`imull %ebx, %eax`<br><br>  <br><br>**单操作数(隐含):**<br><br>  <br><br>`mull %ebx` | 双操作数是 `eax = eax * ebx`。单操作数 `mull` 会隐式把 `%eax` 和操作数相乘，64位结果存入 `%edx:%eax`。 |
| **idiv / div**                          | 除法 (有符号/无符号) | `int q = a / b;`<br><br>  <br><br>`int r = a % b;`      | `idivl %ebx`                                                                                                  | **单操作数指令**！隐含被除数是 64 位的 `%edx:%eax`。除以 `%ebx` 后：**商存入 `%eax`，余数存入 `%edx`**。 |
| **cltd**<br><br>  <br><br>_(cwtd/cbtw)_ | 符号扩展         | `a / b` 运算前的**必须动作**                                    | `movl a, %eax`<br><br>  <br><br>**`cltd`**<br><br>  <br><br>`idivl %ebx`                                      | `cltd` 没有操作数。它负责看 `%eax` 的最高位(符号位)，如果是1，就把 `%edx` 全填1；如果是0，`%edx` 全填0。      |
### 3. 逻辑移位类
| **指令**        | **功能说明**       | **C语言代码**                                       | **对应的汇编实例 (AT&T语法)**                                   | **考点与避坑提示**                                                                      |
| ------------- | -------------- | ----------------------------------------------- | ------------------------------------------------------ | -------------------------------------------------------------------------------- |
| **and**       | 按位与            | `a = a & b;`<br><br>  <br><br>`a = a & 0xFF;`   | `andl %ebx, %eax`<br><br>  <br><br>`andl $0xFF, %eax`  | **考点：掩码（Masking）**。常用来把特定位清零，或者提取特定位的数据。                                         |
| **or**        | 按位或            | `a = a \| b;`<br><br>  <br><br>`a = a \| 0x01;` | `orl %ebx, %eax`<br><br>  <br><br>`orl $0x01, %eax`    | **考点：设置位**。常用来强行把特定位置为 1，且不影响其他位。                                                |
| **xor**       | 按位异或           | `a = a ^ b;`<br><br>  <br><br>`a = 0;`          | `xorl %ebx, %eax`<br><br>  <br><br>`xorl %eax, %eax`   | **必考神技：清零**！`xorl %eax, %eax` 比 `movl $0, %eax` 机器码更短，执行更快，几乎所有编译器清零都会用它。        |
| **sal / shl** | 左移（逻辑/算术同义）    | `a = a << k;`                                   | `shll $2, %eax`<br><br>  <br><br>`shll %cl, %eax`      | **考点：乘以 $2^k$**。注意，移位量如果是变量，**必须且只能放在 `%cl` 寄存器里**，绝对不能写 `shll %ebx, %eax` 这种代码！ |
| **sar**       | **算术**右移       | `int a;`<br><br>  <br><br>`a = a >> k;`         | `sarl $2, %eax`                                        | **地狱级考点：有符号数除法**。右移时，左边空出来的位**补原来的符号位**（正数补0，负数补1）。                              |
| **shr**       | **逻辑**右移       | `unsigned a;`<br><br>  <br><br>`a = a >> k;`    | `shrl $2, %eax`                                        | **考点：无符号数除法**。极其冷酷，不管三七二十一，左边空出来的位**永远补 0**。                                     |
| **test**      | 按位与（不存结果，只设标志） | `if (a & b)`<br><br>  <br><br>`if (a == 0)`     | `testl %ebx, %eax`<br><br>  <br><br>`testl %eax, %eax` | **必考习惯**：`testl %eax, %eax` 常用于判断 eax 是正数、负数还是 0（通过检查 ZF 和 SF），且不改变 eax 的原值。     |
### 4. 控制转移类
| **指令**        | **标志位条件**      | **C语言等价逻辑**                                  | **对应的汇编实例 (AT&T语法)**                                   | **考点与避坑提示**                                                                                     |
| ------------- | -------------- | -------------------------------------------- | ------------------------------------------------------ | ----------------------------------------------------------------------------------------------- |
| **je / jz**   | `ZF=1`         | `if (a == b)`<br><br>  <br><br>`if (a == 0)` | `cmpl %ebx, %eax`<br><br>  <br><br>`je .L1`            | **同义词陷阱**：`je` (相等) 和 `jz` (为零) 机器码完全一样。常配合 `cmp` (判相等) 或 `test` (判为0) 使用。                      |
| **jne / jnz** | `ZF=0`         | `if (a != b)`<br><br>  <br><br>`if (a != 0)` | `cmpl %ebx, %eax`<br><br>  <br><br>`jne .L1`           | **循环核心**：编译器极度喜欢用 `jnz` 来控制 `do-while` 循环的底端跳转。                                                 |
| **jg**        | `SF=OF 且 ZF=0` | `if (a > b)`                                 | `cmpl %ebx, %eax`<br><br>  <br><br>`jg .L1`            | **有符号专用**！代表 Greater (大于)。注意：只要出现了字母 **G** 或 **L**，变量绝对是 `int` 类型！                              |
| **jge**       | `SF=OF`        | `if (a >= b)`                                | `cmpl %ebx, %eax`<br><br>  <br><br>`jge .L1`           | 同上。判断依据是：减法结果要么没溢出且为正，要么溢出了但原本确实是正。                                                             |
| **jl**        | `SF≠OF`        | `if (a < b)`                                 | `cmpl %ebx, %eax`<br><br>  <br><br>`jl .L1`            | **有符号专用**！代表 Less (小于)。极易出错的地方：溢出标志位 OF 的反转会导致判断翻转。                                             |
| **jle**       | `SF≠OF 或 ZF=1` | `if (a <= b)`                                | `cmpl %ebx, %eax`<br><br>  <br><br>`jle .L1`           | 前面的卷子原题考过！看到 `jle`，C 语言里绝对对应着 `<=` 的有符号比较。                                                      |
| **ja**        | `CF=0 且 ZF=0`  | `if ( (unsigned)a > (unsigned)b )`           | `cmpl %ebx, %eax`<br><br>  <br><br>`ja .L1`            | **无符号专用**！代表 Above (高于)。注意：只要出现了字母 **A** 或 **B**，变量绝对是 `unsigned` 类型！                           |
| **jb**        | `CF=1`         | `if ( (unsigned)a < (unsigned)b )`           | `cmpl %ebx, %eax`<br><br>  <br><br>`jb .L1`            | 无符号低于（Below）。底层其实就是借位标志（Carry Flag），因此 `jb` 等价于 `jc`。                                           |
| **jmp**       | **无条件**        | `goto L1;`<br><br>  <br><br>`switch(a)`      | **直接**: `jmp .L1`<br><br>  <br><br>**间接**: `jmp *%eax` | **地狱级考点：间接跳转**。看到 `jmp *0x40000(,%eax,4)` 这种带星号的，**100% 是在考 `switch-case` 语句的跳转表（Jump Table）**！ |
**关键认知**：CMP 不区分有无符号，是后面的 Jxx 指令决定了比较方式。

## 弱点记录

- [ ] 偏移量 = i × sizeof(type)：int→×4, short→×2, char→×1
- [ ] 内存→内存禁止，必须经寄存器中转
- [X] `()` 寻址内部必须是**寄存器**，不能直接填变量名
- [ ] 写回数组元素不是 `(%ebx)` 而是 `(%ebx, %esi, S)`
- [ ] OF vs CF 条件跳转的区别：G/L 系列看有符号，A/B 系列看无符号
- [ ] `jg` 语义是"大于就跳"，跳过了 then 分支，需调整分支结构

# 第三讲：汇编基础与寻址方式

## 一、基础符号系统（AT&T 格式）

| 符号                                     | 含义       | 示例                                          |
| ---------------------------------------- | ---------- | --------------------------------------------- |
| `%`                                    | 寄存器前缀 | `%eax`, `%ebx`                            |
| `$` | 立即数前缀 | `$100`, `$0x1A` |            |                                               |
| `b/w/l`                                | 长度后缀   | `movb`(8位), `movw`(16位), `movl`(32位) |

**AT&T vs Intel 格式**：源和目的顺序相反。

- AT&T: `movl $100, %eax`（源→目的）
- Intel: `mov eax, 100`（目的←源）

---

## 二、七大寻址方式

核心公式：**EA = 位移量 + 基址寄存器 + 变址寄存器 × 比例因子**

| #  | 寻址方式   | 格式             | EA             | 等价 C           |
| -- | ---------- | ---------------- | -------------- | ---------------- |
| ① | 立即       | `$n`           | n 本身         | `int x = 100;` |
| ② | 寄存器     | `%R`           | R 的值         | `x = a;`       |
| ③ | 直接       | `addr`         | addr           | `x = global;`  |
| ④ | 寄存器间接 | `(%R)`         | `[R]`        | `x = *p;`      |
| ⑤ | 变址       | `X(%R)`        | `R+X`        | `x = p[3];`    |
| ⑥ | 基址加变址 | `X(%BR,%IR,S)` | `X+BR+IR×S` | `arr[i]`       |

**比例因子 S**：1(char), 2(short), 4(int/float), 8(double/long long)

**两条铁律**：

- 源和目的不能同时为内存操作数
- 立即数不能做目的操作数

## 三、核心指令

### 1. 传送类

| 指令                 | 功能            | 注意                     |
| -------------------- | --------------- | ------------------------ |
| `mov[b/w/l]`       | 数据传送        | 不影响标志位             |
| `movs[b/w][b/w/l]` | 符号扩展传送    | 高位填符号位             |
| `movz[b/w][b/w/l]` | 零扩展传送      | 高位填 0                 |
| `lea`              | 取地址/地址计算 | **不访存**，仅计算 |

**LEA vs MOV 关键区别**：

```asm
leal 8(%ebp), %eax   ; eax = ebp+8（算地址）
movl 8(%ebp), %eax   ; eax = *(ebp+8)（取数据）
```

### 2. 算术运算类

| 指令               | 功能                                   |
| ------------------ | -------------------------------------- |
| `add/sub`        | 加减                                   |
| `inc/dec`        | 自增/自减                              |
| `neg`            | 求补（取反+1）                         |
| `cmp`            | 做减法，只设标志，不存结果             |
| `imul/mul`       | 乘法（单操作数隐含 eax）               |
| `idiv/div`       | 除法（隐含 edx:eax，商→eax，余→edx） |
| `cbtw/cwtd/cltd` | 符号扩展（除法前必用）                 |

### 3. 逻辑移位类

| 指令              | 功能                  | 等价         |
| ----------------- | --------------------- | ------------ |
| `and`           | 按位与                | 屏蔽/测试    |
| `or`            | 按位或                | 设置位       |
| `xor %eax,%eax` | 清零（比 movl $0 快） |              |
| `sal/shl`       | 左移（两者相同）      | ×2ⁿ        |
| `sar`           | 算术右移（补符号位）  | 有符号 ÷2ⁿ |
| `shr`           | 逻辑右移（补 0）      | 无符号 ÷2ⁿ |
| `test`          | 按位与，只设标志位    | 检测         |

### 4. 控制转移类

| 指令        | 条件           | 含义           |
| ----------- | -------------- | -------------- |
| `jz/je`   | ZF=1           | 零/等于        |
| `jnz/jne` | ZF=0           | 非零/不等      |
| `jg`      | SF=OF, ZF=0    | 有符号大于     |
| `jge`     | SF=OF          | 有符号大于等于 |
| `jl`      | SF≠OF         | 有符号小于     |
| `jle`     | SF≠OF 或 ZF=1 | 有符号小于等于 |
| `ja`      | CF=0, ZF=0     | 无符号高于     |
| `jb`      | CF=1           | 无符号低于     |
| `jmp`     | 无条件         | 直接/间接跳转  |

**关键认知**：CMP 不区分有无符号，是后面的 Jxx 指令决定了比较方式。

## 弱点记录

- [ ] 偏移量 = i × sizeof(type)：int→×4, short→×2, char→×1
- [ ] 内存→内存禁止，必须经寄存器中转
- [X] `()` 寻址内部必须是**寄存器**，不能直接填变量名
- [ ] 写回数组元素不是 `(%ebx)` 而是 `(%ebx, %esi, S)`
- [ ] OF vs CF 条件跳转的区别：G/L 系列看有符号，A/B 系列看无符号
- [ ] `jg` 语义是"大于就跳"，跳过了 then 分支，需调整分支结构

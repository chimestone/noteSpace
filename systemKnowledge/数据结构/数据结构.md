# 数据结构

## 一.绪论

1. 数据:    
所有能输入到计算机中并被计算机程序加工、处理的符号的总称。
2. 数据元素:
数据的基本单位。（元素、记录、结点、顶点）
3. 数据项:
数据的不可分割的最小单位。
4. 数据对象:
性质相同(类型相同)的数据元素组成的集合。
5. 数据结构:
分为逻辑结构（面对问题）、
物理结构（面向计算机）
6. 数据对象在计算机中的组织方式:
逻辑结构
物理存储结构
7. 逻辑结构:即数据之间的相互关系
    分类：  集合  线性结构    树形结构    图状结构
        线性结构又分为：线性表  栈  队列，双队列    数组    字符串
8. 物理存储结构：数据的逻辑结构在计算机存储器中的映像/表示
    分类：顺序存储结构  非顺序存储结构  索引存储结构    哈希存储结构
9. 数据类型：
   1.  原子类型（int float char等）
   2.  结构类型（数组 struct等）
10. 算法的五个特征：
    1.  有穷性
    2.  确定性
    3.  可行性
    4.  0或多个输入
    5.  至少一个输出
11. 算法设计要求：
    1.  正确性
    2.  可读性
    3.  健壮性
    4.  高效与低存储量
12. 复杂度：
    1.  时间复杂度T(n)
    2.  空间复杂度S(n)
## 二.线性表
1. 线性表：由n(n≥0)个数据元素(a1,a2,...,an)构成的有限序列
2. 操作：
   1. 构造空表
   2. 销毁线性表
   3. 线性表置空
   4. 线性表判空
   5. 求表长
   6. 取某元素
   7. 插入删除元素
   8. 排序
   9. 线性表合并
   10. 线性表复制
3. 线性表的顺序表示（顺序存储结构）：一维数组
b+(n-1)*p
b->表的首地址
p->一个数据元素所占存储单元的数目
LOC(i)=LOC(1)+(i-1)*p
LOC(i)->第i个元素所在地址
4. 线性表顺序结构在c语言中的定义：
   1. 静态分配
    ```C
    #define maxlen 100
    typedef struct {
        ElemType elem[maxlen];//下标:0,1,...,    maxlen-1
        int length;            //表长，表中元素个数
    } SqList;
    SqList La;
    ```
    2. 动态分配
    ```C
    #define LIST_INIT_SIZE 100
    #define LISTINCREMENT 10
    typedef struct {   
        ElemType *elem;//存储空间基地址
        int length;    //表长
        int listsize;   //当前分配的存储容量
        //（以sizeof(ElemType)为单位
    } SqList;
    SqList Lb;
    ```
5. 顺序存储结构的评价：
   1. 优点：
      1. 是一种随机存取结构，存取任何元素的时间是一个常数，速度快
      2. 结构简单，逻辑上相邻的元素物理上同样相邻
      3. 不使用额外指针，节省存储空间
   2. 缺点：
      1. 插入/删除元素要移动大量元素，消耗大量时间
      2. 需要一个连续的存储空间
      3. 插入元素可能溢出
      4. 自由区的存储空间不能被其他数据占用
6. 线性表的链式存储结构（非顺序存储结构）：链表
7. 单链表的结点结构：节点类型与指针类型：

## 三.栈,队列

   1. 定义：只在栈顶做插入（push），删除（pop）
   2. 表头：栈底    表尾：栈顶
   3. 别名：“后进先出”表，"LIFO"表，反转存储器，地窖，堆栈
   4. 基本操作：
      1. 构造空栈
      2. 栈置空
      3. 元素进栈
      4. 删除栈顶元素
      5. 栈判空
   5. 栈的线性结构
   ```C
   #define  STACK_INIT_SIZE     100
   #define  STACKINCREMENT   10
   typedef   struct{ 
   ElemType *base；    //指向栈元素空间
   int top；                    //栈顶指示
   int stacksize               //栈元素空间大小，
   } SqStack；                // SqStack为结构类型
   SqStack s；           //s为结构类型变量
   ```
   6. 链式栈：
   ```C
   struct node {
    ElemType data;      //data为抽象元素类型
    struct node *next;  //next为指针类型
   } *top=NULL;         //初始化，置top为空栈，top为头指针
   ```
   7. 顺序栈&链式栈：
      1. 二者push/pop操作时间复杂度均为O(1)
      2. 顺序栈对存储空间要求严格，需要判断满栈，但出入栈操作简单
      3. 链式栈存储灵活；但是出入栈要对指针操作

## 九.查找
1. 平均查找长度ASL： 查找一个记录时比较关键字次数的平均值,设待查找的关键字值为k
   1. ASL=∑ PiCi
        Pi --- 查找到r[i].key=k的概率
        Ci --- 查找到r[i]所需比较关键字的次数
2. 若 n = 2h -1,则判定树为满二叉树,其深度为 h=log2(n+1)
   1. ASL=(n+1)/n * log2(n+1) -1
   2. 对任意的n ASL≈上式
3. 平衡二叉树：(AVL树)
   1. 结点的平衡因子：结点的左右子树的深度之差
   2. 平衡二叉树：任意结点的平衡因子的绝对值小于等于1的二叉树
4. B-树：
   1. 一棵m阶B-树，或为空树，或为满足下列特性的m叉树：
   （1）树中每个结点至多有m棵子树；
   （2）若根结点不是叶子结点，则至少有两棵子树；
   （3）除根之外的所有非终端结点至少有m/2(向上取整)棵子树；
   （4）所有的非终端结点中包含下列信息数据

# 信源和信宿的数学模型
信源：
$$(^X_{P(X)})=(^{a_1\,a_2\,...\,a_i ...\,a_n}_{p(a_1)\,p(a_2)\,...\,p(a_i)\,...\,p(a_n)})$$
其中$p(a_i)$满足：
$$
0\leq p(a_i)\leq 1,\sum ^n _{i=1}p(a_i)=1
$$信宿：
$$(^Y_{P(Y)})=(^{b_1\,b_2\,...\,b_i ...\,b_m}_{p(b_1)\,p(b_2)\,...\,p(b_i)\,...\,p(b_m)})$$
其中$p(b_i)$满足：
$$
0\leq p(b_i)\leq 1,\sum ^m_{i=1}p(b_i)=1
$$

## 单符号离散信道容量定义
**定义**：
$$
C = \max_{p(a_i)} I(X; Y)
$$
注意：
- 此处会涉及最大熵定理（**注意可达性**）
- 信道容量是描述信道特征的参量，是信道的最大传信能力
- 与信源无关
## 特殊离散信道的信道容量
### **离散无噪信道的信道容量**
**具有一一对应关系的无噪无损信道**
转移矩阵每行有且仅有一项为1。
$$
C = \max_{p(a_i)} I(X; Y) = \log n
$$
信道容量仅取决于输入符号数n。
**具有扩展功能的无损有噪信道**
一个输入对应多个输出。[[第4章 离散信道容量.pdf#search=具有扩展性能的无损有噪信道|指路]]
特殊性质：每列有且仅有一个元素非零。
$$
H(X / Y) = 0; H(Y / X) \not = 0
$$
$$
C = \max_{p(a_i)} I(X; Y) = \log n
$$
**具有归并性能的无噪有损信道**
性质与上述相对。
$$
C = \max_{p(a_i)} I(X; Y) = \log m
$$
离散无噪信道的信道容量只与输入符号数/输出符号数有关，与信源无关。
### **对称离散信道的信道容量**
***强对称*离散信道的信道容量**
[[第4章 离散信道容量.pdf#search=强对称离散信道的信道容量|指路]]
$$
C = \max_{p(a_i)} [H(Y) - H(Y/X)] = \log n - H_{ni}
$$
$$
H_{ni} = H(1-p, \frac{p}{n-1},..., \frac{p}{n-1})
$$
转移概率矩阵若列可排列，那么信源等概可推出信宿等概。
反之，行可排列，那么信宿等概可推出信源等概。

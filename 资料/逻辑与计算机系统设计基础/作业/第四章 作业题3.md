设计一个判断1位余3码范围的电路，当输入余3码的值为3，4，5时，F1输出为1；当输入余3码的值为6，7，8，9时，F2输出为1；判断F1和F2是否存在竞争？是否存在险象？给出完整的解题过程

---

竞争与险象分析
$$F2 = AB + AD + AC$$
不存在竞争与险象。
$$F1 = BC + A\overline{B}\overline{C}\overline{D}$$
$B$$\overline B$,$C$$\overline C$均同时出现，均具备竞争条件。
固定各变量：
$A=1, D=0$：$F1 = BC + \overline{B}\overline{C}$，含 $B\overline{B}$ 和 $C\overline{C}$，存在险象。
$D=0$：$F1 = BC + A\overline{B}\overline{C}$，含 $B\overline{B}$ 和 $C\overline{C}$，存在险象。
F1存在竞争，存在险象
险象出现条件：$A=1, D=0$ 时，$BC$ 从 $10\to01$ 或 $01\to10$ 变化，过渡瞬间 $F1=0$，产生静态1型险象。

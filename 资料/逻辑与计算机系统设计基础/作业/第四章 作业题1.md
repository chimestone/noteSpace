$$F = A\overline{A}C + AM + \overline{A}C\overline{M} + \overline{M}M = AM + \overline{A}C\overline{M}$$

其中$$M = (B + \overline{C})(\overline{B} + C) = \overline{B}\overline{C} + BC$$

$$\overline{M} = \overline{B}C + B\overline{C}$$
代入得
$$F = A(\overline{B}\overline{C} + BC) + \overline{A}C(\overline{B}C + B\overline{C})$$

# 社团招新数据处理工具使用说明

## 🎯 这个工具能做什么？

- 统计各个时段的参与人数
- 生成人数统计图表
- 筛选特定条件的学生
- 合并不同表格的学生信息

## 📋 使用前准备

1. 确保你的电脑已安装 MATLAB 软件
2. 准备好以下文件：
   - 招新活动收集的Excel表格
   - 需要补充信息的基础名单表格

## ⚙️ 如何修改设置

**所有设置都在 `load_config()` 函数中（第25-59行），只需要修改这一个地方！**

### 1. 更换数据文件

**找到第28-30行，修改文件路径：**

```
config.input_filename = "你的招新数据表格路径";
config.output_filename1 = "基础名单表格路径";
config.output_filename2 = "最终输出表格路径";
```

### 2. 调整数据列位置

**如果你的Excel表格列顺序不同，修改第32-41行：**

```
config.name_col = 3;     ← 姓名在第几列就改成几
config.age_col = 4;      ← 年级在第几列就改成几
config.tel_col = 5;      ← 电话在第几列就改成几
config.qq_col = 6;       ← QQ在第几列就改成几
config.from_col = 7;     ← 部门在第几列就改成几
```

### 3. 修改时段安排

**如果活动时段不同，修改第43-47行：**

```
config.sat_slots = {"你的周六时段1", "你的周六时段2", ...};
config.sun_slots = {"你的周日时段1", "你的周日时段2", ...};
```

### 4. 更改筛选条件

**修改第49-52行来改变筛选规则：**

```
config.intention_keyword = "是";           ← 改成你表格中表示"有意向"的词
config.target_grades = {"24级", "23级"};   ← 改成你要筛选的年级
config.target_department = "文艺拓展部";    ← 改成你要筛选的部门
```

### 5. 自定义图表

**修改第54-59行来改变图表样式：**

```
config.chart_title = "各时段参与人数统计";  ← 改成你想要的图表标题
config.x_label = "时段";                   ← 改成横轴标签
config.y_label = "人数";                   ← 改成纵轴标签
```

## 🚀 如何运行

1. 打开 MATLAB 软件
2. 打开 `chuli.m` 文件
3. 按照上面的说明修改设置
4. 点击"运行"按钮或按 F5 键

## 📊 运行结果

运行完成后你会得到：

- 一个显示各时段人数的柱状图
- 一个包含完整联系信息的Excel表格

## ❗ 常见问题

**Q: 提示"找不到文件"怎么办？**
A: 检查文件路径是否正确，确保文件确实存在

**Q: 图表显示不正常怎么办？**
A: 检查时段描述是否与Excel表格中的内容完全一致

**Q: 筛选结果为空怎么办？**
A: 检查筛选关键词是否与表格中的内容匹配

**Q: 合并表格失败怎么办？**
A: 确保两个表格都有姓名列，且姓名格式一致

## 🔧 代码结构说明

代码现在采用模块化设计，包含以下模块：

- **配置模块**：所有设置都在 `load_config()` 函数中
- **时段统计模块**：处理各时段人数统计
- **数据可视化模块**：生成图表
- **筛选模块**：筛选特定学生
- **导出模块**：合并和导出数据

## 💡 小贴士

- **只需修改配置模块**：所有个性化设置都在 `load_config()` 函数中
- 修改设置时只需要改引号内的内容
- 文件路径要用完整路径，包含盘符
- 中文内容要保持与Excel表格完全一致
- 运行前先保存修改的设置
- 如果需要添加新功能，可以创建新的模块函数

# DPLL算法自然语言描述

## 基础DPLL算法

**工作步骤：**
1. **找必须的赋值**：找到只有一个变量的子句，必须给这个变量赋值
2. **检查矛盾**：看看有没有子句变成假的，有就说明走错路了
3. **判断完成**：所有变量都有值了就成功
4. **试探分支**：选第一个没赋值的变量，先试真再试假
5. **回退重试**：走不通就退回来试另一条路

**特点：** 按顺序选变量，简单但可能要试很多次。

## 优化DPLL算法

**工作步骤：**
1. **找必须的赋值**：和基础版本一样
2. **检查矛盾**：和基础版本一样
3. **判断完成**：和基础版本一样
4. **聪明选变量**：
   - 数一数哪个变量在未解决的子句里出现最多
   - 选出现最多的变量来试
5. **回退重试**：和基础版本一样

**特点：** 优先选"最热门"的变量，通常能更快找到答案。

## 主要区别

- **基础版本**：像排队一样按顺序选变量
- **优化版本**：像选班长一样选"得票最多"的变量

优化版本更聪明，因为选择影响最大的变量，能一次性解决更多问题。
